# 什么是 Long（做多）

## 一句话解释

**Long（做多）= 先买后卖，赌涨。**

你觉得某个币要涨 → 现在买入 → 涨了卖出 → 赚差价。

## Long vs Short

| | Long（做多） | Short（做空） |
|------|------------|-------------|
| 方向 | 赌涨 | 赌跌 |
| 操作 | 先买后卖 | 先卖后买 |
| 盈利条件 | 价格上涨 | 价格下跌 |
| 最大亏损 | 本金归零 | 理论上无限（价格可以无限涨） |

## 杠杆 Long

在交易所（如币安合约）可以用杠杆放大收益/亏损：

| 杠杆倍数 | BTC 涨 10% | BTC 跌 10% |
|---------|-----------|-----------|
| 1x（现货） | 赚 10% | 亏 10% |
| 3x | 赚 30% | 亏 30% |
| 10x | 赚 100% | **爆仓（亏光）** |
| 20x | 赚 200% | 跌 5% 就爆仓 |

## 新手建议

| 规则 | 为什么 |
|------|--------|
| 先玩现货（1x），别碰杠杆 | 杠杆是加速亏钱的工具 |
| 如果要用杠杆，最多 3x | 留足够的容错空间 |
| 一定设止损 | 不设止损 = 等爆仓 |
| 别用全部资金开仓 | 永远留子弹 |
