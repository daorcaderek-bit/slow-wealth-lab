# 如何在 Pons 上交易

## Pons 是什么

Pons 是一个 DEX 交易平台，操作逻辑与 Uniswap 类似——连接钱包，选择交易对，直接 Swap。

## 交易步骤

### 1. 连接钱包

1. 打开 Pons 官网
2. 点击 "Connect Wallet"
3. 选择你的钱包（MetaMask / Rabby 等）
4. 确认连接

### 2. Swap 交易

1. 选择要卖出的代币（From）
2. 选择要买入的代币（To）
3. 输入金额
4. 检查滑点设置
5. 点 "Swap" → 钱包确认 → 等待成交

### 3. 添加流动性（进阶）

如果你想赚交易手续费分成：

1. 找到 "Pool" 或 "Liquidity" 页面
2. 选择交易对（如 ETH/USDC）
3. 存入等值的两种代币
4. 确认 → 开始赚手续费

> 注意：添加流动性有"无常损失"风险，新手建议先只做 Swap。

## Pons vs Uniswap 对比

| 维度 | Pons | Uniswap |
|------|------|---------|
| 支持的链 | 视平台支持 | 以太坊 + 多条 L2 |
| 手续费 | 视具体设置 | 0.3%（标准池） |
| 界面 | 较简洁 | 功能更全 |
| 代币覆盖 | 特定链的代币 | 以太坊生态最全 |

## 通用 DEX 交易注意事项

- 第一次交易某代币需要先 **Approve**（授权），这是正常的
- 交易完成后在钱包里 **Import Token** 才能看到余额
- 大额交易分批做，避免滑点过大
- 留够 Gas 费（别把 ETH 全部换完）
