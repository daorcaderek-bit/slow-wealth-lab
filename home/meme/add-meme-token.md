# 如何在钱包里添加 Meme 代币

## 为什么钱包里看不到我买的币？

钱包默认只显示主流代币（ETH、USDT 等）。新发的 Meme 代币需要手动添加合约地址，钱包才能显示。

## MetaMask 添加代币

1. 打开 MetaMask
2. 确认你在正确的网络（比如 Robinhood Chain）
3. 滚动到底部 → 点 "Import tokens"
4. 粘贴代币的**合约地址**（Contract Address）
5. 代币符号和小数位会自动填充
6. 点 "Add Custom Token" → 确认

## 合约地址去哪找？

| 来源 | 网址 |
|------|------|
| Dexscreener | https://dexscreener.com |
| DEX 的交易页面 | 交易对详情里有 |
| 项目方 Twitter/TG | 官方发布的 CA |
| 区块链浏览器 | Etherscan / 对应链的浏览器 |

## 防骗指南

- **永远从官方渠道获取合约地址**，不要信私信
- 在 Dexscreener 上检查：
  - 流动性是否锁定
  - 持币集中度（前10名持有>80%？危险）
  - 合约是否开源验证
- 搜一下合约地址，看是否有"蜜罐"（Honeypot）标记——买得进卖不出
