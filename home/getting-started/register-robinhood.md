# 如何注册 Robinhood

## 前提条件

- 美国居民身份（SSN 社会安全号）
- 18 岁以上
- 有效的美国地址

> **非美国用户注意：** Robinhood 目前仅对美国居民开放。如果你在新加坡/中国大陆，可以考虑用币安或 OKX 作为替代，链上交易直接用钱包连 DEX 即可。

## 注册步骤

1. 下载 Robinhood App（iOS / Android）或访问 https://robinhood.com
2. 点 "Sign Up"
3. 填写个人信息（姓名、邮箱、SSN）
4. 身份验证（上传驾照或护照）
5. 等待审核（通常几分钟到1天）
6. 绑定银行账户 → 入金

## 开启加密交易

1. 注册完成后，进入 App
2. 搜索 "Crypto" 或任何加密货币名称
3. 首次交易会要求开通加密交易权限
4. 同意协议 → 即可买卖

## 开启链上钱包（Robinhood Wallet）

1. App 内搜索 "Wallet" 或在设置中找到 "Web3 Wallet"
2. 创建链上钱包
3. 备份助记词
4. 现在你可以把币转到链上，参与 DEX 和 Meme 交易

## 入金方式

| 方式 | 到账时间 | 费用 |
|------|---------|------|
| 银行转账（ACH） | 1-3 个工作日 | 免费 |
| 电汇（Wire） | 当天 | $25-50 |
| 借记卡 | 即时 | 1.5% |
