# 钱包注册方法

## MetaMask（以太坊 / Robinhood Chain）

### 安装

1. 打开 https://metamask.io
2. 点 "Download" → 选择你的浏览器（推荐 Chrome）
3. 安装浏览器插件

### 创建钱包

1. 打开 MetaMask 插件 → 点 "Create a new wallet"
2. 设置密码（本地密码，用于解锁插件）
3. **备份助记词（最重要的一步）**
   - 系统会显示 12 个英文单词
   - 用纸笔抄下来，按顺序
   - **不要截图、不要存手机、不要存云盘**
4. 按顺序确认助记词 → 完成

### 添加 Robinhood Chain 网络

1. MetaMask 左上角点网络名称
2. 点 "Add network" → "Add a network manually"
3. 填入 Robinhood Chain 的网络参数（官方文档会提供 RPC URL、Chain ID 等）
4. 保存

---

## Phantom（Solana）

### 安装

1. 打开 https://phantom.app
2. 点 "Download" → 选择浏览器或手机
3. 安装

### 创建钱包

1. 打开 Phantom → "Create a new wallet"
2. 设置密码
3. **备份助记词**（同样的规则：纸笔抄写，不要截图）
4. 完成

---

## 注册后必做的 3 件事

| 步骤 | 操作 | 为什么 |
|------|------|--------|
| 1 | 助记词抄在纸上锁好 | 丢了 = 资产永久丢失 |
| 2 | 先转小额测试 | 确认地址正确再转大额 |
| 3 | 收藏官方网址 | 防钓鱼网站 |
