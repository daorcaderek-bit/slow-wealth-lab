# 滑点、Gas费、MEV 防坑指南

## 滑点（Slippage）

**滑点 = 你预期的成交价 vs 实际成交价的差距。**

| 设置 | 适用场景 |
|------|---------|
| 0.5-1% | 主流币（ETH、BTC） |
| 3-5% | 中等流动性代币 |
| 10-15% | Meme 币 / 新币 |
| >15% | 大概率有问题，小心蜜罐 |

**滑点设太低** → 交易失败
**滑点设太高** → 被机器人夹（三明治攻击）

---

## Gas 费

**Gas = 链上交易的手续费**，付给矿工/验证者。

| 链 | 单笔 Swap Gas 费 | 等级 |
|-----|-----------------|------|
| 以太坊主网 | $2-50 | 贵 |
| Robinhood Chain | <$0.01 | 极便宜 |
| Base | <$0.01 | 极便宜 |
| Arbitrum | $0.1-0.5 | 便宜 |
| Solana | <$0.01 | 极便宜 |

**省 Gas 技巧：**
- 用 L2 链交易（Robinhood Chain、Base、Arbitrum）
- 避开以太坊主网高峰时段
- 合并操作（别一笔笔小额交易）

---

## MEV（三明治攻击）

**MEV = 机器人看到你的交易 → 抢在你前面买入 → 你的交易推高价格 → 机器人卖出赚差价。**

你亏的就是机器人赚的。

### 怎么防

| 方法 | 操作 |
|------|------|
| 用 MEV 保护 RPC | MetaMask 设置中替换 RPC 为 Flashbots Protect |
| 降低滑点 | 滑点越高，被夹空间越大 |
| 拆分大额交易 | $10,000 分5次，每次 $2,000 |
| 用聚合器 | 1inch、CowSwap 内置 MEV 保护 |

### Flashbots Protect 设置（MetaMask）

1. MetaMask → 设置 → 网络 → 以太坊主网
2. RPC URL 改为：`https://rpc.flashbots.net`
3. 保存 → 你的交易就会通过 Flashbots 提交，对 MEV 机器人不可见
