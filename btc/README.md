# 比特币会归零吗？

这的确是一些看空加密行业的主流观点。

我不从“比特币的稀缺性，只有2100万枚，也不讲它数字黄金的储值属性，也不讲为什么能够在没有银行背书的情况下运行这些底层区块链密码学的东西，想必大家听过太多次了。

### 我们换一个更长的时间视角

从人类经济发展的角度，看比特币和Crypto（包括加密货币、稳定币、区块链、链上结算、资产代币、钱包协议、生态）到底在解决什么问题。

过去人类几百年的经济发展来看：

{% hint style="info" %}
经济增长，本质上就是不断扩大人类可以连接、交易和调用资源的半径。
{% endhint %}

过去很多真正改变经济结构的技术，本质上都做了同一件事。

铁路扩大商品运输的半径。

航运扩大全球贸易的半径。

金融扩大了资本跨时间、跨地域配置的半径。

互联网扩大了信息传播的半径。

今天，你发一条消息给在美国的人，几乎已经感觉不到距离。你也可以凌晨三点给世界另一端的人发一封邮件。

但是钱，到今天依然没有真正全球化。

想一个场景：凌晨三点把100万从一个地域转到另一个地域：你的银行 → SWIFT 报文 → 中间代理行 → 收款银行 → 最终到账

账户、营业时间、付款指令、外汇兑换、合规审核、跨境清算、不同国家的金融体系……这个资本逻辑在1973年成立，已经运行半个多世纪了。

### Crypto真正要解决的

钱有没有可能像信息一样，在全球网络中流动？

答案是“极有可能”，我也非常相信Crypto实际上正在解决：扩大资本的流动半径。

过去的钱，大多数存在银行数据库里。

你的100块，只属于某家银行、某个国家、某套金融体系。

而稳定币第一次让我们看到另一种可能：

只要拥有互联网连接和钱包地址，它就可以被转移、储存、交易，甚至被程序直接调用。

这件事情的意义远超过“交易比特币”。

### 你想想未来的样子

从本地账户 → 全球账户

从银行营业时间 → 7×24小时

从跨境清算 → 全球实时结算

从人工金融流程 → 软件和智能合约自动执行

如果继续，就是Tokenization资产代币化。

今天全球金融体系里：

股票是一套系统，债券是一套系统，基金是一套系统，房地产又是一套系统，不同国家之间又完全不同。

很多资产虽然价值巨大，但流动性其实非常差。

未来如果股票、债券、基金、房地产、黄金，甚至未来收入的一部分等等等等，都可以被映射成数字资产，那么金融市场的资产开始像信息一样，在全球网络中流动。

回到问题：比特币和加密货币会慢慢消亡么？单纯讲Token，这一类我认为绝大多数最终都会消失。它们没有持续现金流，没有真正的网络效应，也没有不可替代的使用场景。这堆垃圾牛市出生熊市灭亡。

就像互联网泡沫时期大量网站最后归零一样，互联网没有消亡，消亡的是那些没有价值的网站。

但是金融基础设施。比如稳定币、结算网络、交易网络、借贷协议、资产发行平台。他们是有价值的。

看有没有真实资金在上面流动，有没有企业使用，有没有资产在上面发行，有没有形成生态效应，有没有比传统金融更便宜、更快、更开放。

### 比特币需要单独拿出来看

因为它真正特殊的地方，不是支付，是第一次让一种不依赖单一国家金融系统的资产，可以原生存在于全球数字网络中。

你可以问自己，或者从国家地域角度观察：大家是否需要在全球资产配置体系里，需要一种原生于互联网、可以跨越国界存在和转移的资产。

如果需要，那么比特币就长期拥有自己的位置，且永远不会归零。

当然，这条路绝对不会是直线。

未来5年，很可能是，token会越来越少，真正有价值的网络会越来越集中。

#### 持续观察和思考的

全球资本未来是不是会越来越数字化。

稳定币是不是会成为互联网的货币层。

股票、债券和基金是不是会越来越多地上链。

AI Agent未来进行交易和支付时，会不会天然使用数字资产和智能合约？

全球结算是不是会从T+1、T+2逐渐走向实时？

{% hint style="info" %}
如果这些趋势最终成立，那么Crypto真正创造的将会是一套新的金融操作系统。
{% endhint %}

如果人类经济史真的一直在做同一件事情——

不断降低连接成本，

不断降低交易成本，

不断扩大资源配置半径，

那么从这个视角看，稳定币、区块链和资产代币化将是确定的。

#### 十年以后

全球有多少美元在链上流动，

多少股票、债券和基金在链上结算，

多少AI Agent开始自主完成支付和交易，

以及全球有多少价值，开始像今天的信息一样，几乎无摩擦地流动。

如果那一天真的到来，今天的比特币上涨和下跌，只是整个故事最早期、也最喧闹的一部分。

真正的大故事，才刚刚开始。
