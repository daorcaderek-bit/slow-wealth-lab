# 如何找百倍 Meme

## 残酷的真相

99% 的 Meme 币会归零。百倍是小概率事件，但有方法提高胜率。

## 筛选框架

### 第一层：数据筛选

用 Dexscreener / DEX Screener 过滤：

| 指标 | 筛选条件 | 为什么 |
|------|---------|--------|
| 市值 | < $500K | 太大了涨不动 |
| 流动性 | > $10K | 太低买不进卖不出 |
| 创建时间 | < 24小时 | 越早发现越好 |
| 交易笔数 | 持续增长 | 有真实买盘 |
| 持币人数 | 持续增长 | 不是几个人对倒 |

### 第二层：叙事判断

好 Meme 的特征：

- **强叙事** — 蹭热点（Elon 发推、政治事件、文化梗）
- **好名字** — 一看就懂，有传播性
- **社区活跃** — TG群在聊天，Twitter在转发，不是死群
- **Logo 出圈** — 能做表情包的logo更容易传播

### 第三层：链上验证

| 检查项 | 工具 | 红旗 |
|--------|------|------|
| 蜜罐检测 | Honeypot.is | 买得进卖不出 |
| 合约权限 | TokenSniffer | 能增发/暂停交易 |
| 持币分布 | Etherscan | Top10 持有 > 50% |
| 流动性锁定 | DEXTools | 未锁定=可能 Rug |

## 仓位管理（最重要）

- 单个 Meme 最多投总资金的 **2-5%**
- 翻倍先卖一半回本
- 10倍再卖一半
- 剩下的当彩票持有
- **亏光一个 Meme 不应该影响你的生活**
