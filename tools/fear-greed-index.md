# 恐惧贪婪指数怎么看

## 什么是恐惧贪婪指数

一个 0-100 的数字，衡量市场情绪：

| 区间 | 情绪 | 含义 |
|------|------|------|
| 0-25 | 极度恐惧 | 大多数人在恐慌卖出 |
| 25-45 | 恐惧 | 市场悲观 |
| 45-55 | 中性 | 观望 |
| 55-75 | 贪婪 | 市场乐观，FOMO 情绪 |
| 75-100 | 极度贪婪 | 大多数人在追高买入 |

## 数据来源

**加密市场：** alternative.me/crypto/fear-and-greed-index

计算因素：
- 价格波动率（25%）
- 交易量（25%）
- 社交媒体热度（15%）
- 问卷调查（15%）
- BTC 市值占比（10%）
- Google Trends（10%）

## 怎么用

### 巴菲特法则

> "别人恐惧我贪婪，别人贪婪我恐惧。"

| 指数 | 操作建议 |
|------|---------|
| 0-25（极度恐惧） | 考虑加仓，历史上是好的买入点 |
| 25-50（恐惧） | 正常定投，可以稍微多买 |
| 50-75（贪婪） | 正常定投，不追高 |
| 75-100（极度贪婪） | 减少投入，考虑止盈 |

### 不能单独使用

恐惧贪婪指数是**辅助指标**，不能作为唯一决策依据：
- 2021年5月 F&G 跌到 10 → 之后确实反弹了
- 但2022年6月 F&G 跌到 6 → 之后又跌了几个月

**正确用法 = F&G + 估值百分位 + 基本面，综合判断。**

## 多市场情绪对比
